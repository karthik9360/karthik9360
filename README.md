## 🔭 What I'm Building

### 🏗️ Crane Monitoring System
> Real-time WebSocket infrastructure for industrial crane operations

Tracking **hoist cycles**, **load events**, and **operator activity** live from the field using Django Channels and a React dashboard. This system handles concurrent telemetry streams, conditional aggregation, and sub-second UI updates.

**Key challenges solved:**
- 🔌 Django Channels `WebSocketConsumer` with Redis channel layer
- 📊 Conditional `Sum()` aggregation using Django's `Q()` objects
- ⚛️ React real-time metric updates with WebSocket event listeners
- 🐛 Debugged double-filtering bugs & suppressed real-time update patterns
